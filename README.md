Funcionamiento:
Las entradas se muestran como cuadrados que se ponen verdes cuando el pulsador está activado.
Las salidas se muestran como círculos: L1 se pone rojo y L2 amarillo cuando el LED está encendido.
Al hacer clic sobre un círculo, el LED correspondiente se enciende o se apaga.
La comunicación se hace por puerto serie
